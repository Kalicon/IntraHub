Arquitetura de Sincronização Online do Banco Local

Como o servidor hospitalar local se comunica com o servidor de licenciamento remoto:

1. Banco de Dados Local
O banco H2/Postgres local armazena a chave ativada e valida a assinatura HMAC offline sem depender da internet.
2. Checagem Diária HTTPS
Uma rotina em segundo plano consulta a API central remota para verificar revogações ou renovações automáticas.
3. Modo Air-Gapped / Off-line
Caso a internet do hospital caia, o sistema permanece 100% operacional pela validação criptográfica em memória.
